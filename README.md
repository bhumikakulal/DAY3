## 3. Explanation of Aggregate Functions Used

Aggregate functions perform a calculation on a set of values in a column and return a single summary value:

* **COUNT()**: Calculates the total number of rows or non-NULL values matching the specified criteria.
* **SUM()**: Calculates the total combined sum of a numeric column.
* **AVG()**: Computes the average (arithmetic mean) of numerical values in a column.
* **MAX()**: Returns the highest/maximum value found in the selected column.
* **MIN()**: Returns the lowest/minimum value found in the selected column.
